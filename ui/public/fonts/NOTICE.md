# Fonts

The browser client self-hosts two Latin fonts. Both are licensed under the
SIL Open Font License, Version 1.1. The full license text is in `OFL.txt`.

- **Schibsted Grotesk** — Copyright 2023 The Schibsted-Grotesk Project Authors
  (https://github.com/schibsted/schibsted-grotesk).
- **Geist Mono** — Copyright 2024 The Geist Project Authors
  (https://github.com/vercel/geist-font).

The Space serves these files from its own origin. The client does not request
fonts from a third-party network.
