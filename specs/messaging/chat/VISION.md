# Chat

## Why

On Sunday evening the user tells the writer the launch is Friday. By morning the draft is in the Chat, the research behind it is linked, and a question waits under it.

Chat is the floor of Neha: the place where one User and one teammate talk. It has to work for someone who has learned nothing about the product, and it has to make "what happened while I was away" visible at a glance.

## What

A Chat is the conversation between one User and one Bot.

Each User allowed to use a Bot has one Chat with it. The owner's Chat is created and removed with the Bot; the owner sets who else can use it.

A Bot's work in a Chat is implicit: the User asks, the Bot works, and the result lands in the stream as a Message.

A Chat keeps its whole history.

A Chat shows one of three states in the sidebar: working, unread, or waiting for the User.

## Why this way

One Chat per User and Bot keeps memory continuous and the sidebar honest: the row is the teammate, and opening it is talking to them. The owner decides who else gets that row.

That work stays implicit because one teammate working for one User needs no card; the result and the question are Messages like any other.

The state belongs to the Chat itself, so what needs the User is one glance away and no separate view is needed.

## Principles

- **One Chat per User and Bot.** Each User allowed to use a Bot has one Chat with it; the owner's is created with the Bot and lasts as long.
- **Results land in the stream.** Whatever the Bot produces appears in the Chat where the work was given, as a Message.
- **Calm on the surface.** Progress is one collapsed line, and the Bot's internal steps appear when the User asks for them.
- **State is visible at a glance.** A Chat shows working, unread, or waiting for the User, and the User sees it without opening the Chat.
- **Asks in the Chat.** A Bot's question or approval appears in the Chat where the request was made, and the User who asked answers.

## What this enables

- Anyone who can chat can use Neha.
- A User with many Bots scans one list and knows what needs them.
- Results, approvals, and questions live where the User already is.
