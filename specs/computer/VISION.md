# Computer

## Why

The user has a laptop, a home PC, and a server. They want a Bot on each that knows that machine — its files, its logins, its installed software — and they want to reach any of them from the phone in their pocket.

This is what sets Neha apart. A Bot's actions run on a Hosted Computer or on a Local Computer a User controls; on the Local one, its files, logins, and software are the machine's own. The user reaches it from any client, its screen is a panel in the Chat, and it keeps working when the client is closed.

## What

A Computer is the machine a Bot's actions run on: a Hosted one that Neha provides, or a Local one a User controls.

A new Bot starts on its owner's Space Computer. Its owner can create it on another Computer they own instead.

A Local Computer is a machine a User controls. It runs Neha's Computer process, connects out to the Space, and stays reachable from any client.

A Bot has one Computer, and several Bots can share one.

A Computer's screen is a panel in the Chat: the user can watch, take over, and hand back.

## Why this way

A Bot starts on its owner's Space Computer because that works without setup. The owner can create it on another Computer when the work is there.

A Hosted Computer lets a user start with no machine of their own, or keep a Bot away from the machine it runs on.

Neha's Computer process on the machine, connecting out to the Space, is what lets that machine stay reachable without accepting inbound connections.

A Computer shared by several Bots keeps their capabilities honest: each does what its machine can do, and nothing else.

The panel is part of the Chat because watching a Bot work on the user's own machine is how the user comes to trust it, and taking over is how the user helps when it is stuck.

## Principles

- **A Space Computer by default.** A new Bot starts on its owner's Space Computer; its owner can create it on another Computer instead.
- **A Local Computer runs Neha.** A machine a User controls becomes a Computer that connects out and is reachable from any client.
- **One Computer at a time, shared when wanted.** A Bot's capabilities are its machine's; several Bots can share one Computer.
- **The machine's screen is a panel.** A user can watch a Bot work, take over, and hand back, from the Chat.

## What this enables

- A Bot whose actions run on a machine the User controls and learns it.
- Getting things done from any client, with the client closed and the Bot still working.
- Several Bots sharing one machine's processes, logins, and Workspace, each in its own directory.
