# Computer

## Why

The user has a laptop, a home PC, and a server. They want a Bot on each that knows that machine — its files, its logins, its installed software — and they want to reach any of them from the phone in their pocket.

This is what sets Neha apart. A Bot runs on a managed Computer or on a machine the user owns; on the user's machine, its files, logins, and software are the machine's own. The user reaches it from any client, its screen is a panel in the Chat, and it keeps working when the client is closed.

## What

A Computer is the machine a Bot runs on: a managed one that Neha provides, or a real one the user owns.

A new Bot lives on a managed Computer. Its owner can move it to a real machine.

A real Computer is a machine with Neha installed on it; it connects to the Space and stays reachable from any client.

Each Bot has its own Computer, and several Bots can share one.

A Computer's screen is a panel in the Chat: the user can watch, take over, and hand back.

## Why this way

A managed Computer by default lets a user start with no machine of their own and nothing to set up.

Moving to a real machine is the owner's choice because that is where a Bot touches the user's actual files and logins; it is a step taken knowingly, not a default.

Neha installed on the machine, connecting out to the Space, is what lets a Bot live behind a home router or a company network and still be reached from anywhere.

Each Bot having its own Computer keeps a Bot's capabilities honest: it can do what its machine can do, and nothing else.

The panel is part of the Chat because watching a Bot work on the user's own machine is how the user comes to trust it, and taking over is how the user helps when it is stuck.

## Principles

- **Managed by default, real by choice.** A new Bot lives on a managed Computer; its owner moves it to a real one when ready.
- **A real Computer runs Neha.** Installing Neha on a machine makes it a Computer that connects out and is reachable from any client.
- **One Computer per Bot, shared when wanted.** A Bot's capabilities are its machine's; several Bots can point at the same machine.
- **The machine's screen is a panel.** A user can watch a Bot work, take over, and hand back, from the Chat.

## What this enables

- A Bot that lives on the user's own PC, laptop, or server and learns it.
- Getting things done on any of them from any client, with the client closed and the Bot still working.
- Several Bots sharing one machine's files and logins when the owner wants that.
