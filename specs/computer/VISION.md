# Computer

## Why

The user has a laptop, a home PC, and a server. They want a Bot on each that knows that machine — its files, its logins, its installed software — and they want to reach any of them from the phone in their pocket.

This is what sets Neha apart. A Bot runs on a Hosted Computer or on the Local Computer where Neha runs; on the Local one, its files, logins, and software are the machine's own. The user reaches it from any client, its screen is a panel in the Chat, and it keeps working when the client is closed.

## What

A Computer is the machine a Bot runs on: a Hosted one that Neha provides, or the Local one where Neha runs.

A new Bot starts on a Hosted Computer. Its owner can create it on the Local Computer where Neha runs instead.

A Local Computer is the machine where Neha runs; it connects to the Space and stays reachable from any client.

Each Bot has its own Computer, and several Bots can share one.

A Computer's screen is a panel in the Chat: the user can watch, take over, and hand back.

## Why this way

A Bot starts on a Hosted Computer because that works without setup. The owner can create it on the machine where Neha runs when the work is there.

A Hosted Computer lets a user start with no machine of their own, or keep a Bot away from the machine it runs on.

Neha installed on the machine, connecting out to the Space, is what lets that machine stay reachable without accepting inbound connections.

Each Bot having its own Computer keeps a Bot's capabilities honest: it can do what its machine can do, and nothing else.

The panel is part of the Chat because watching a Bot work on the user's own machine is how the user comes to trust it, and taking over is how the user helps when it is stuck.

## Principles

- **A Hosted Computer by default.** A new Bot starts on a Hosted Computer; its owner can create it on the Local Computer where Neha runs instead.
- **A Local Computer runs Neha.** The machine where Neha runs becomes a Computer that connects out and is reachable from any client.
- **One Computer per Bot, shared when wanted.** A Bot's capabilities are its machine's; several Bots can point at the same machine.
- **The machine's screen is a panel.** A user can watch a Bot work, take over, and hand back, from the Chat.

## What this enables

- A Bot that lives on the machine where Neha runs and learns it.
- Getting things done from any client, with the client closed and the Bot still working.
- Several Bots sharing one machine's processes and logins, each with its own Workspace.
