# Bot

## Why

On a Friday the user creates a writer, gives it one job and two rules, and by the next launch it still knows the rules, the voice, and where the drafts live.

A Bot is the teammate. It has to remember, be trustworthy, and be its owner's to shape, with no settings page standing between the user and the conversation.

## What

A Bot is a persistent identity: a name, a picture, a memory, and a Computer it lives on.

A Bot remembers what it learns in its Chats and Groups and carries it forward. The user shapes its behavior by telling it, and it keeps lasting rules in memory.

A Bot lives on a Computer: the Local one where Neha runs, or a Hosted one Neha provides.

The owner sets who else can use the Bot: only the owner, everyone, or specific Users.

A Bot has a page for what conversation cannot hold: name, picture, Computer, access, the Model it thinks with, and the memory it keeps.

A Bot's work is in progress, waits for the User, or is done. While it runs, the User can redirect it with a Message or stop it.

## Why this way

Memory belongs to the Bot, not to a Chat; a template copies the Bot's `owner` rules that still apply and no `note`.

Behavior is shaped in conversation because that is where preferences are discovered; the page holds only what has to be visible and revocable, and the Model a Bot thinks with.

A Bot starts on a Hosted Computer because that works without setup. The owner can create it on the machine where Neha runs when the work is there.

Access is the owner's to give because the Bot is the owner's; what it does for another User, it does under that User's authority.

## Principles

- **A Bot remembers, and a template carries the Bot's `owner` rules that still apply but not its notes.** Memory belongs to the Bot; what it learns in one conversation it carries to the next.
- **Behavior is shaped in conversation.** Lasting preferences and rules live in memory; the page holds only name, picture, Computer, access, Model, and the memory it keeps.
- **A Hosted Computer by default.** A new Bot starts on a Hosted Computer; its owner can create it on the Local Computer where Neha runs instead.
- **Access is the owner's to give.** The owner decides who else can use the Bot: only the owner, everyone, or specific Users.
- **Visible while it works.** A User sees that a Bot is working, can redirect it with a Message, and can stop it.

## What this enables

- A teammate that gets better at the user's work over time.
- A Bot for one machine that learns it.
- Sharing a Bot that already knows the work.
- Enhancements on this shape: a template, a built-in helper Bot, a Schedule that starts work at a time, and a Watcher that starts work when a condition is met. A template carries the Bot's `owner` rules that still apply, without notes or its Chats.
